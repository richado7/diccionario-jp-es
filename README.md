### Qué hace este proyecto
- `palabras.json` -> guarda las palabras
- `lasvocales.py` -> categorías por separado
- `categoria.py` -> el jefe que llama a todos en orden (ya no son niños de kinder corriendo)
- `diccionario_01.py` -> versión completa con menú

Usa `try/except` para no romperse y `if __name__ == "__main__":` para controlar los imports.
